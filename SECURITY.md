# Security reports

Use this repository's private vulnerability reporting option under Security →
Advisories when it is enabled. If it is unavailable, open an issue requesting a
private contact channel without including credentials, personal data or exploit
details. Do not use the historical example email or PGP values as verified contacts.

Reports should identify the affected commit, entry point, expected boundary and
an isolated reproduction. A passing CI badge does not certify a deployment.

Private channel when enabled: [GitHub Security Advisories](https://github.com/blistartunivers-afk/blist-security-baseline/security/advisories/new).
